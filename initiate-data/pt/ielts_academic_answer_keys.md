## 4. Rencana Implementasi Auto-Scoring di IELC-CRM

1. **Normalisasi String**:
   - Case-insensitive (jadikan lowercase sebelum dicocokkan).
   - Trim whitespace dan punctuation (tanda kurung, tanda petik).
   - Menghapus kata penjelas opsional seperti `(the)`, `(hotel)`, `(meat)`.
2. **Kombinasi Urutan Acak (*Any Order / Either Order*)**:
   - Reading Q23 & Q24: Set `{ 'C', 'D' }`.
   - Reading Q25 & Q26: Set `{ 'B', 'E' }`.
   - Listening Q25, Q26, Q27: Set `{ 'safe for children', 'educational', 'inexpensive/cheap/good price' }`.
3. **Penyimpanan Nilai**:
   - Raw Score: `0 - 40`
   - Estimated Band Score: `1.0 - 9.0`
   - Skor otomatis disimpan ke tabel `pt_sessions` / `pt_ielts_answers` saat sesi dikirim (*submit*).
